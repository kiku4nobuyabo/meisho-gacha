## セットアップ後の最小確認

1. PCとスマホを同じ非公開記録リポジトリに接続。
2. 初期シーズンと、区分設定済み武将を含む初期プールを保存。
3. PCで+1 → 同期済みを確認 → スマホで同期 → 同じ1回が表示されること。
4. スマホで直近1件を戻す → 同期 → PCでも0に戻ること。
5. S武将を選ぶ画面でキャンセル → 回数が増えないこと。
6. スマホ画面に横スクロールがなく、名前の開始位置とカードサイズが揃っていること。

テスト入力の取消履歴はログに残るが、集計に含まれない。

## v0.1.3 GitHub接続修正

ブラウザ標準fetchをクラスのプロパティ経由で未bind呼び出ししていたため、ChromeでIllegal invocationになる問題を修正。globalThis.fetch.bind(globalThis)を使用する。
